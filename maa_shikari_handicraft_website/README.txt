MAA SHIKARI HANDICRAFT HANDLOOM — WEBSITE PACKAGE

FILES
- index.html: main website
- style.css: design, layout and responsive styling
- script.js: mobile navigation, collection filters and image viewer
- images/: original image files extracted from your uploaded ZIP

HOW TO OPEN
1. Extract maa_shikari_handicraft_website.zip to a folder on your computer.
2. Open the folder.
3. Double-click index.html. It should open in Chrome.
4. Keep index.html, style.css, script.js and the images folder together.
5. To edit text, right-click index.html and choose Edit with Notepad++.
6. To change the design, edit style.css. For interactions, edit script.js.

IMAGE NOTES
- Original supplied image files are kept in the images folder; the website uses them directly.
- The gallery automatically includes all image files found in the supplied ZIP.
- Product headings are generated from filenames, so please check them and adjust wording in index.html if a filename is ambiguous.
- The attached ZIP contained 30 photograph/image files plus an image-placeholder.svg asset. No separate shop poster was found in the ZIP, so the hero styling uses the supplied shop-hero.jpg image as its visual lead.
- The email and Janjehli shop address are included. No phone number was added because one was not provided.

ONLINE PUBLISHING
Upload the complete extracted folder contents to your hosting provider (for example, Cloudflare Pages). Do not upload only index.html: keep the images folder and both CSS/JS files.
